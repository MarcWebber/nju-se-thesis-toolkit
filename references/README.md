# 论文参考

写作与文风校准直接读取用户指定的参考原文。本机材料见 `local/index.md`；公开论文候选见 [南大硕士论文](nju-masters-2025-2026.md)。候选名单不等于已读范文。

## 本地材料

`local/` 保存 PDF 和一份阅读索引，由 Git 忽略，并排除在默认发布包之外。手动上传和打包时，按本次任务另行确认文件范围。

替换参考时放入新文件，更新 `local/index.md` 中的题名、版本、文件名及阅读位置。旧稿的页码和评价不能沿用。复制 Skill 到其他项目时，另行提供参考文件或索引路径。

## 使用

1. 按本次任务选读参考中的相应章节，核对正文与图表页面。索引只负责定位，不代替原文。
2. 记录值得借鉴的段落展开、证据组织和图文配合方式，并标出具体页码。参考存在的缺陷也要记录。
3. 用作者自己的材料写作。不能换词复述参考段落、重画他人的独有图示后作为原创，也不能移入其中的数据、实现和结论。采用他人研究观点时须核对并引用来源。
4. 他人论文用于文体参考，不代表用户个人文风；个人文风需另有用户自己的样文。内容修改和评论在飞书完成。

```text
参考 references/local/index.md 中的论文及相关原页，
用我的仓库和飞书方案修改“系统实现”一节。
借鉴说明机制的方式，保留我的事实和术语。
先在对话中给修改建议，确认后写回飞书。
```
