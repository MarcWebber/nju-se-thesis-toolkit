# 写作指南

## 材料与范围

先读取作者指定的文档和本次材料。需要本地参考时，查看当前工作目录的 `references/local/index.md`，按索引读取相关原文与图表。项目事实、系统关系、个人写作偏好和当前稿件状态保存在本地资料中，按本次范围选读。

参考论文用于理解章节组织、论证推进和图文配合，借鉴依据标到具体原文。写作采用作者自己的事实、数据与图示；引用他人的研究观点时核对来源。个人文风以作者样文为依据，学校格式以当年要求为准。

材料整理者沿用作者确认的系统名称、业务主体、组件职责和贡献范围，分别标明作者原话、原始事实和分析建议。作者指定外部写作者时，交付当前目标、相关材料、来源及学院要求，写作者自主决定题目、提纲、取舍、段落和图文组织。

## 共用规则

1. 按作者最新确认的范围处理，保留认可的章节、已有修订、原始文献引用键、图源与材料定位。
2. 正文区分有来源的工程事实、实验结果与分析结论；待核事项和制作记录另行保存。
3. reviewer 只交评审建议，正文与文件保持原样；writer 或作者负责题目、组织、措辞和修订，发布者原样回填选定稿件并回读。
4. 标题直接指出实际对象或问题，段落围绕清楚的论证关系自然展开。技术细节按解释需要放入对应章节，有作者样文时参考其表达习惯。
5. 先验收系统理解、论证与阅读体验，再核对格式、图件和文件。分别报告内容认可、实际阅读范围、页面检查与工具运行结果。
6. 合成示例用于说明操作和写法，作者材料用于支持项目事实。

## 外部写作

写作者、模型和调用入口沿用作者当前选择。执行者在调用前后核对实际入口、模型和生成结果，保留原始回答。额度或模型变化时暂停该轮写作，来源待核输出保存在工作记录。

[角色文件](../agents/agent.yaml)说明职责，模型调用由当前会话实际执行。评审建议包含原文位置、依据与修改方向，写作者判断并执行修订。

## 使用方式

1. 在支持 Skill 的 AI 助手中调用 `nju-se-thesis`，附上本次目标、材料和输出位置。助手按 [任务入口](../SKILL.md#写作任务) 读取对应指令。
2. 在普通对话中，引用本页的[共用规则](#共用规则)与所选任务指令，再附材料与请求。文件操作按对应工具参考执行。
3. 在需要处理文件时调用 toolkit CLI；读取飞书、制作画板和使用学校平台时，直接使用已有外部工具。

## 写作顺序

1. 整理材料与提纲，确定本文问题及其证据。
2. 根据问题阅读文献，比较可用方法与实际约束。
3. 按需起草章节，结合代码与数据制作图表。
4. 在飞书合稿，修订事实、术语、引用和图文一致性；用 `$thesis-calibrate` 按样文审阅并留下局部评论。
5. 内容确认后处理模板、编译与交付。

这个顺序用于作者安排工作。已有正文、图件或 TeX 工程时可从对应任务开始，每一步都可以单独执行。

## 人工介入

1. 作者可以直接改飞书正文、提供替换段落、调整提纲或修改图源。助手先读取最新内容，再处理本次指定范围。
2. 要求“只审不改”时只提供意见；要求“只写这一节”时完成这一节；要求“继续”时承接最近确认的位置。
3. 需要换任务时，沿用已确认事实、术语和引用，不依赖前一步生成的专用配置文件。
4. 飞书是内容源稿。生成的 TeX 只改排版配置；发现已有 TeX 内容改动时保留文件，向作者指出差异，确认后回填飞书再转换，不自动覆盖或双向合并。

## Example

```text
使用 nju-se-thesis，根据这份飞书方案和仓库中的预约模块，
只写系统实现章的“并发预约处理”一节。
先读调用入口、事务和唯一约束的实际代码。
保留原文的术语与引用键，交付正文和一张时序图。
时序图使用飞书画板，另交源文件、SVG 和矢量 PDF。
没有性能数据，不写性能提升；无需改业务仓库。
```

```text
使用全文修订 Prompt，只检查我的摘要、结果表和总结。
核对数字、指标定义与结论范围，不修改原稿。
每个问题给出位置、依据和具体修改建议。
```

## 模板

- 本工具集以 `nju-lug/NJUThesis v1.5.1` 为默认配置基线，使用时另行准备上游发布包。
- 在主 TeX 文件的文档类选项中设置 `type=master` 和 `degree=professional`，参见 [v1.5.1 示例](https://github.com/nju-lug/NJUThesis/blob/v1.5.1/template/njuthesis-sample.tex)。配套 YAML 不会代替这些设置。
- 上游示例默认 `fontset=win`。CLI 保留导入工程的字体设置；编译前确认字体可用，并核对学院要求。
- 若使用 `references.bib`，还须将其配置到 TeX 工程的文献数据源，参见 [文献配置](https://github.com/nju-lug/NJUThesis/blob/v1.5.1/template/njuthesis-setup.def)。
- 本地编译使用 `latexmk -xelatex`。在线协作时保留本地源文件和备份。
- 当年学院或研究生院通知优先。发现冲突时记录，不擅自修改模板类文件。

## 送审自检

使用 `dongshao/nju-se-thesis-self-check` 时，读取上游当前 `SKILL.md` 和工程型论文检查清单，报告中保留页码定位。结果仅供自查。
