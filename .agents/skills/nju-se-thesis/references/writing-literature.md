# 文献与相关工作

配合 [共用规则](nju-se-engineering.md#共用规则) 使用。

## 1. 输入

```text
本节问题：
文献原文、链接或引用键：
需要比较的机制：
已有正文：
产物：阅读记录 / 比较表 / 相关工作正文 / 引文核验
```

## 2. 阅读与比较

1. 需要检索时，从研究对象、机制和评价指标形成中英文关键词，优先寻找原始论文与官方技术文档。
2. 按下表记录已读内容。只取得摘要或书目信息时，在阅读记录中注明，不补写未读细节。
3. 按共同问题组织文献，例如去重位置、事务边界或故障恢复方式。比较适用条件与代价，不按作者顺序逐篇复述。
4. 不同环境、负载或数据集的数字分别说明，不能直接据此给方法排名。
5. 相关工作正文说明方法之间的关系及其与本文约束的联系。资料获取情况、待查问题放在正文后的备注，不混入论文段落。

| 来源与定位 | 解决的问题 | 方法 | 验证条件与结果 | 适用限制 |
|---|---|---|---|---|
| 原文链接、章节或页码、引用键 | 对象与场景 | 实际机制 | 环境、指标与观察 | 原文限制与本项目差异 |

### 知网

1. 使用现有浏览器登录态直接检索。当前工作目录的 `.cnki.local.json` 保存 `phone`，需要登录时读取；文件缺省不影响已有会话。登录态由浏览器保存。
2. 在[硕士论文高级检索](https://kns.cnki.net/kns8s/AdvSearch?dbcode=CMFD)选择“学位授予单位”，填写“南京大学”，按用户要求设置学位年度。按院系补充学科专业或已知题名、作者。
3. 核对题名、作者、学位年度、专业和 DOI。入库年、评优年分别记录；优秀论文依据学校或学院公告，下载量只作检索线索。
4. 从结果或详情页打开原版阅读或下载。遇到验证码交用户完成，随后继续当前页面；登录失效才重新登录。临时下载链接不作为可复用入口。
5. 保存取得的全文到 `references/local/`，在索引记录来源、页码、可借鉴之处和缺陷。只有摘要或试读时如实标注；直接阅读指定原文，不额外生成一套写作规则。

## 工具接入

检索和 DOI 元数据核对使用 `literature-search` 与 `reference-check`；Zotero 导出通过 `bibliography` 保留引用键；PDF 与扫描件使用 `read-paper` 保存原页定位。先读 [接入说明](integrations.md)，确认所需依赖和输入。候选元数据、解析文本和作者论断分别核对，不能把解析成功当作文献阅读完成。

## 3. 引文核验

1. 来源存在：打开原始来源，不能仅凭搜索摘要或他人参考文献认定已核验。
2. 书目准确：核对作者、题名、年份、载体和标识符，不补猜 DOI。
3. 支持论断：核对引用位置及其条件；文献存在不等于支持当前句子。
4. 著录一致：保留作者已有引用键，按指定模板检查格式和重复条目。
